# Session handoff

Use this file when handing unfinished work to the next agent session or human
reviewer.

## What to capture

- the current task boundary
- important files touched
- verification status
- risks or caveats
- the safest way to resume

## Suggested handoff format

## Handoff

- Task:
- Status:
- Files:
- Verified:
- Risks:
- Resume from:
