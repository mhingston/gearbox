# Session progress

Use this file as the lightweight running log for work that spans more than one
agent session.

## What to capture

- current goal
- what changed this session
- what is still in progress
- blockers or open questions
- the next concrete action to take

## Suggested entry format

## YYYY-MM-DD

- Goal:
- Completed:
- In progress:
- Blockers:
- Next step:
